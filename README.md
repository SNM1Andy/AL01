# AL-01 · 人工生命研究原型

本项目探索自定义认知语言 C.L、个体状态连续性及有限环境中的反馈学习。它是研究程序，不是已证明具有意识或通用智能的生命。

## 本快照

包含 candidate010 的 82 个 Python 源文件，逐字保留原源码。这里的最小命令只演示 P0/P1 基础运行，不是完整蓝图，也不是实验004/005复现入口。完整实验原始证据尚未纳入公开包，避免把只有汇总的发布误称为可完整独立复现。

## 本地基础演示

使用 Python 3.13；完整模块集合还使用 numpy。原实验记录环境为 Python 3.13.5、numpy 2.5.4。建议新建虚拟环境安装依赖，勿在含有重要文件或凭据的目录运行实验。

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m al01 --steps 20 --objects 10 --output runs/demo
```

命令生成 checkpoint.json、events.jsonl、report.json、observatory.html。程序内限制不是操作系统安全沙箱；文件代理等其他模块不建议面向个人真实数据启用。

## 学习是什么，不是什么

已测学习机制由人设计：固定候选动作、探索规则、奖励和更新公式。个体的计数和价值随自己的回执更新，并非预填最终偏好；但有限任务内的变化不能称为无约束自发智能。当前尚未证明自行编写 C.L 词典、自然语言交流、一般化迁移或意识。自然语言模型不应冒充个体的内部认知。

见 EXPERIMENT_LOG.md、RELEASE_SCOPE.md。默认不启用教师，不把旧状态升级或解释为新个体。
