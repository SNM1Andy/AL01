## 本次公开内容

- [原生证明复验脚本](../examples/native-proof-smoke.py)。它在临时目录创建合成命题与测试状态，分别用独立 CL 编译包和原生 PCGM 求证，检查五步状态：未知 → 正向支持 → 冲突 → 反向支持 → 未知。
- 正反假设在各自的 CL 测试包中推演，不写入 PCGM 个体。撤回真实测试观察后，推理重算；导出并恢复后核对身份和结论。
- 本次实跑使用 Linux x86-64 CPU、CL 0.157 和 PCGM 0.159（alpha）。脚本使用 Python 标准库调度复验，不是 CL 或 PCGM 的运行依赖。本次提交不包含原生可执行文件。

```sh
python3 examples/native-proof-smoke.py /path/to/cl /path/to/pcgm-alpha
```

预期逐行输出 `UNKNOWN`、`POSITIVE`、`CONFLICT`、`NEGATIVE`、`UNKNOWN`，最后打印 `PASS`。
